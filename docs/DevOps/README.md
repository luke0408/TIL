# DevOps

DevOps 카테고리는 인프라 운영, 배포 자동화, 서비스 안정성처럼 개발 이후 단계에서 필요한 실무 개념을 다룹니다. IaC 관점의 [Pulumi](./Pulumi/README.md)와 문서 검색 인프라 관점의 [Algolia DocSearch](./algolia_docsearch.md)를 중심으로 운영 관점을 정리합니다.
