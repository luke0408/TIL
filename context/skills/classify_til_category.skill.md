# Skill: classify_til_category

## Purpose
Map a topic to the correct docs category.

## Decision
- Principle-focused -> `docs/DevGeneral/Principle/`
- AI/ML concept -> `docs/AI_ML/`
- Retrieval/indexing/vector operations -> `docs/AI_ML/RAG/`
- Book material -> `docs/Book/<book-title>/`

If ambiguous, ask a one-line clarification question.
