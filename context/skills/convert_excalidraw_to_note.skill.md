# Skill: convert_excalidraw_to_note

## Purpose
Convert Excalidraw text/diagram content into markdown notes.

## Steps
1. Extract text elements and chapter markers.
2. Group by topic.
3. Create one-note-per-topic markdown files under `docs/`.
4. Keep raw drawing files in `assets/excalidraw/`.
5. Do not commit `*.canvas` files.
